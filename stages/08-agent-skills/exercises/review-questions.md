# Review questions

1. Why is a Skill not simply a long system prompt?
2. Why is a Skill not equivalent to a Tool or MCP server?
3. What problem does progressive disclosure solve?
4. What metadata is loaded before activation?
5. Why must `allowed-tools` never be treated as authorization by itself?
6. Design a skill whose scripts require network access. What should `compatibility` say and what runtime policy still remains necessary?
7. How would you route among 200 installed skills without loading 200 full bodies?
8. What should be traced/versioned when comparing skill v1 and v2?
9. Review the bundled `research-review` skill for supply-chain and context risks.
10. Build an eval proving whether the skill improves research-grounding quality over a no-skill baseline.
